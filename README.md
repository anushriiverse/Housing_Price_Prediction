<h1> Housing Price Prediction Model </h1>
The dataset was trained on multiple models to test its accuracy by measuring the lowest error it possibly made. 
The <b>linear regression</b> model made an error of $60,000 while the <b>random forest</b> model made an error of approx $50,000
Eventually a <b>Gradient Boosting</b> model was trained to give an error of $46,000.
